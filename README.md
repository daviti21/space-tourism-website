# Space Tourism Website

A responsive multi-page space tourism website built as a Frontend Mentor challenge.

## Features

* Multi-page navigation
* Destination information
* Crew member section
* Technology section
* Responsive design for mobile, tablet, and desktop
* Interactive navigation between pages

## Technologies

* HTML
* CSS
* JavaScript

## Purpose

This project was built to practice responsive layouts, multi-page navigation, complex UI sections, and creating a consistent user experience across different screen sizes.
